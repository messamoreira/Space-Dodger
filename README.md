# Meteor Dodger

## Descrição

Um jogo simples e divertido onde você controla uma nave espacial e desvia de meteoros que caem. O objetivo é sobreviver o maior tempo possível para alcançar a maior pontuação.

## Instalação

Para jogar, você precisa ter o Python e o Pygame instalados.

1.  **Instale o Python:** Se você não tiver o Python instalado, baixe-o em [python.org](https://python.org).
2.  **Instale o Pygame:** Abra o terminal ou o prompt de comando e execute o seguinte comando:
    ```sh
    pip install pygame
    ```

## Como Jogar

1.  **Execute o jogo:**
    ```sh
    python main.py
    ```
2.  **Controles:**
    *   Use a **seta para a esquerda** para mover a nave para a esquerda.
    *   Use a **seta para a direita** para mover a nave para a direita.
3.  **Objetivo:**
    *   Desvie dos meteoros que caem para sobreviver.
    *   Sua pontuação é o tempo que você sobrevive. O jogo termina quando um meteoro atinge sua nave.

Divirta-se!
